          Workspaces
          
      
          
        Each workspace is its own set of projects. Settings — theme, language,
        engine paths — belong to this machine and are shared by all of them.
      
          

      
            

      
            
        
        
      
            

      
            

      
                

    
      
            
        
      
            
      
      
            docmap — know your project
            
      
            
        A window in front of the maps documentation.nvim generates.
      
            
      
            
      
                

    
      
            
        
      
            

      
            Settings
            

      
            
        
            Appearance
            
        
            
          
          
        
            
        
            
          
          
          
        
            
      
            

      
      
            
        
            Behaviour
            
        
            
          
          
        
            
        
      
            

      
            
        
            Engine
            
        
            
          The engine is documentation.nvim's standalone binary —
          this app runs it, it does not replace it. Where it is on PATH there is
          nothing to do here, ever.
        
            
        
            
        
        
            
        
            
          
          
        
            
      
            

      
      
            
        
            Telemetry
            
        
            
          Collected by runtime-analysis.nvim inside Neovim,
          per plugin. Switching it here takes effect from the next Neovim
          session — nothing in this window runs your plugin.
        
            
        
            
        
            
          
        
            
        
            
        
              
      
              


      
              
        
              Editor
              
        
              
          What Open in editor runs, from the map's own
          right-click menu. {file} and {line} are
          substituted. Leave it empty to hand the file to whatever your
          desktop opens it with.
        
              
        
      
              

      
              
        
              Neovim
              
        
              
          Only needed to import plugin specs from a Neovim config. Most
          machines resolve both of these on their own.
        
              
        
              
        
              
          
          
        
              
      
              
                  
    
    
      
              
        
      
              

      
              Project settings
              
      
              

      
              
        
              Languages
              
        
              
          Which languages the engine reads here. Nothing ticked means
          all of them.
        
              
        
                
      
                

      
                
        
                Excluded paths
                
        
                
          One path per line, relative to the project root.
        
                
        
        
                
          
        
                
      
                

      
                
        
                Layout
                
        
                
          Where this repository keeps its code and its map. Leave both empty
          to let the engine decide — it detects the sources itself and writes
          to docs/map, which is right for almost every project.
        
                
        
                
          
          
        
                
        
                
          
          
        
                
      
                

      
                
        
                Source links
                
        
                
          What the view source links in the generated page point at.
          Without a URL the page still works and simply has no links out —
          which is the difference people notice between a map made here and
          one made by the same engine in CI.
        
                
        
                
          
          
        
                
        
                
          
          
        
                
      
                

      
                
        
                Generating
                
        
        
                
          Adds the lua-language-server enrichment behind the
          Types panel. It needs that tool installed, takes longer, and gains
          a non-Lua project nothing — so it is a choice per project, not a
          setting for this machine.
